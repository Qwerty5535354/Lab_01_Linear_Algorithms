# Лабораторна робота № 1. Алгоритми лінійної структури

**Варіант 5.**

## Мета

Ознайомитися з основами Python (змінні, `input`/`print`, арифметика) і реалізувати два лінійні алгоритми.

## Завдання

1. Ввести двоцифрове число та вивести його цифри (десятки й одиниці) через пробіл.
2. Ввести температуру в градусах Цельсія та перевести її у Фаренгейти (`TF = TC * 1.8 + 32`) і Кельвіни (`TK = TC + 273.15`).

## Теорія

* Лінійний алгоритм виконується по черзі: ввід → обчислення → вивід.
* Цифри числа: `//` (ціла частина від ділення) дає десятки (`47 // 10 = 4`), `%` (остача) — одиниці (`47 % 10 = 7`).
* `input()` повертає рядок, тому його перетворюють на `int` або `float`. Некоректне введення перехоплює `try/except ValueError`.
* Для від'ємного двоцифрового числа береться модуль; температура нижча за −273.15 °C неможлива (абсолютний нуль).

## Запуск

Потрібен Python 3.10+ (перевірка: `python --version`). Сторонні бібліотеки не потрібні.

```bash
python main.py
```
